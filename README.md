# LangGPT
(CURRENTLY A WORK IN PROGRESS)

This app is a foreign language practice tool powered by the GroqCloud API. It supports a variety of languages and will eventually have various features that make it a useful tool for practicing languages.

In order to use this app, you must do the following:
1) Install Python 3.12.0 or later (https://www.python.org/downloads/)
2) pip install the following:
   - Pyside6
   - groq

When running the app, you are required to input a GroqCloud API key or the app won't work.
You can obtain a GroqCloud API key as follows:
1) Go to the following link: https://console.groq.com/home
2) Create an account
3) Navigate to "API Keys" and create an API key.
