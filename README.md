# LangGPT
(CURRENTLY A WORK IN PROGRESS)

This app is a foreign language practice tool powered by the GroqCloud API. It supports a variety of languages and will have many features that make it a useful tool for practicing languages.

In order to use this app, you must have a GroqCloud API key and provide it when you start the app. 

You can obtain an API key as follows:
1) Go to the following link: https://console.groq.com/home
2) Create an account
3) Navigate to "API Keys" and create an API key.
